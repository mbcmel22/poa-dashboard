Comment fonctionne la mise à jour automatique

  1. Saisie manuelle : l'onglet POA du Google Sheet reste la base. Chaque valeur saisie apparaît ici au prochain clic sur Actualiser.
  2. Automatisation : un script (Google Apps Script ou Make) ajoute chaque jour ou chaque semaine des lignes dans l'onglet Flux_auto : Date | Code | Valeur | Source.
  3. Fusion : le dashboard regroupe ces lignes par mois. Une valeur automatique remplace la valeur manuelle du même mois.

Le guide complet est dans le fichier GUIDE_AUTOMATISATION.md du projet.
